# Ordo — User & Setup Guide

Marketing Automation for Magento Open Source

This is the setup guide submitted with Ordo's Adobe Commerce Marketplace listing. It is the source
for `Ordo-User-Guide.pdf` (generated by `generate-pdf.py` in this directory) — edit this file, then
regenerate the PDF, rather than editing the PDF directly.

For full feature-by-feature documentation, see the [GitHub Wiki](https://github.com/michalper/ordo/wiki)
— this guide covers installation, configuration, and a feature overview, then links out to the wiki
page for each feature.

## Overview

Ordo is a Klaviyo/HubSpot-style campaign engine (trigger → conditions → actions) that runs directly
inside stock Magento Open Source — no Adobe Commerce B2B license, no per-contact marketing-automation
subscription. Triggers are computed from data Magento already has (orders, quotes, customers, carts),
or from a small first-party data model Ordo adds alongside it.

It covers both classic B2C lifecycle automation (abandoned cart, win-back) and B2B triggers most
external marketing-automation tools can't see at all — credit limit alerts, order approval workflows,
reorder reminders — because they never had access to that data.

## Requirements

- PHP 8.4 or 8.5
- Adobe Commerce / Magento Open Source 2.4.8 or 2.4.9

## Installation

```
composer require michalper/ordo
bin/magento module:enable Ordo_Automation
bin/magento setup:upgrade
bin/magento cache:flush
```

## Configuration

Every feature has its own on/off switch under **Stores → Configuration → Ordo Automation** — each is
off by default until enabled, and each has its own scheduled cron job. If a feature "isn't doing
anything," the first thing to check is its own config toggle, not a shared master switch (there isn't
one).

## Feature Guide

### B2B

| Feature | What it does | Full guide |
|---|---|---|
| Reorder reminders | Reminds a customer to reorder based on their own purchase history | [Reorder Cycles](https://github.com/michalper/ordo/wiki/Reorder-Cycles) |
| Offer/quote expiry reminders | Reminds a customer before a quoted offer expires | [Campaigns](https://github.com/michalper/ordo/wiki/Campaigns) |
| Credit limit alerts | Warns a customer approaching their credit limit, with an optional hard checkout block at 100% | [Dashboard](https://github.com/michalper/ordo/wiki/Dashboard) |
| Order approval workflow | Holds orders above a per-customer spend limit for a token-based admin approve/reject email | [Order Approval](https://github.com/michalper/ordo/wiki/Order-Approval) |
| Free gifts | Automatic gift once a cart crosses a spending threshold, with cascading tiers | [Free Gifts](https://github.com/michalper/ordo/wiki/Free-Gifts) |

### B2C

| Feature | What it does | Full guide |
|---|---|---|
| Abandoned cart recovery | Recovers abandoned carts by email, capped per cart | [Campaigns](https://github.com/michalper/ordo/wiki/Campaigns) |
| Welcome email | Sends on customer registration | [Campaigns](https://github.com/michalper/ordo/wiki/Campaigns) |
| Win-back / re-engagement | Emails a customer after N days of inactivity, self-clears once they order again | [Campaigns](https://github.com/michalper/ordo/wiki/Campaigns) |
| SMS recovery (Twilio) | `send_sms` campaign action with delivery-status tracking and opt-out handling | [Campaigns](https://github.com/michalper/ordo/wiki/Campaigns) |
| WhatsApp (Meta Cloud API) | `send_whatsapp` campaign action with its own template approval lifecycle | [Campaigns](https://github.com/michalper/ordo/wiki/Campaigns) |
| Web Push notifications | `send_push` campaign action, real browser/OS notifications to every subscribed device | [Tracking & Popups](https://github.com/michalper/ordo/wiki/Tracking-and-Popups) |
| Price-drop / back-in-stock alerts | A customer or visitor watches a product; alerts fire on the first real change | [Tracking & Popups](https://github.com/michalper/ordo/wiki/Tracking-and-Popups) |
